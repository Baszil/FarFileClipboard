# FarFileClipboard 1.0 — файловый буфер Windows для Far Manager

Сделал небольшой плагин для Far Manager 3 под x86, x64 и ARM64, который связывает обычную файловую панель Far с системным файловым буфером Windows.

Основная причина появления очень бытовая: хотелось копировать или вырезать файлы в Проводнике и вставлять их прямо в текущий каталог Far, не открывая эту же папку в Проводнике отдельно. Обратное направление тоже работает: файл можно положить в системный буфер прямо из Far и вставить обычным Ctrl+V в Проводнике.

Горячие клавиши по умолчанию:

- `Ctrl+Shift+C` — копировать. Если есть выделение `Insert`, берётся всё выделение; иначе объект под курсором.
- `Ctrl+Shift+X` — вырезать с тем же правилом выбора.
- `Ctrl+Shift+V` — вставить строго в каталог, который сейчас открыт на активной панели.
- `Ctrl+Shift+D` — отдельная команда вставки в каталог под курсором; работает только если под курсором действительно каталог.
- `Ctrl+Shift+Z` — отменить последнюю безопасно обратимую файловую операцию, выполненную самим FarFileClipboard.
- `Ctrl+Shift+E` — повторить только что отменённую операцию.

Обычная вставка никогда сама не заходит в каталог под курсором — это принципиально отдельная операция.

Для обычных файлов плагин использует стандартный файловый буфер Windows (`CF_HDROP` + признак предпочтительной операции), поэтому копирование/вырезание совместимы с Проводником в обе стороны. При вставке в Far есть и Shell-fallback: можно скопировать файлы прямо из ZIP, открытого в Проводнике, и вставить их в обычный каталог Far без предварительной ручной распаковки.

В настройках отдельно выбирается поведение для очевидно недопустимых операций и для конфликтов имён. По умолчанию FarFileClipboard заранее отсекает невозможные случаи вроде каталога внутрь самого себя, а при совпадении имени показывает собственный диалог `Заменить / Пропустить / Переименовать / Отмена` с возможностью применить «Заменить»/«Пропустить» ко всем конфликтам. Можно вместо этого полностью передать конфликт Windows или включить автоматическое переименование входящего объекта по настраиваемому шаблону (по умолчанию `{name} ({n}){ext}`).

Отмена/повтор одноуровневые. Для безопасности операция не записывается в историю, если при вставке уже существовало целевое имя и Windows могла выполнять замену или слияние. Перед отменой и повтором проверяется идентичность файловых объектов и отсутствие конфликтов.

В `F11` отображается один пункт `FarFileClipboard`, внутри него находится меню команд. Есть русская и английская локализация `.lng`, встроенная справка `.hlf`, настройки всех горячих клавиш и исходники C++/CMake.
