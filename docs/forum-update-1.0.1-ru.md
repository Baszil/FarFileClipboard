# Обновление темы: FarFileClipboard 1.0.1

Выложил FarFileClipboard 1.0.1. Главное изменение — теперь опубликованы отдельные сборки для x86, x64 и ARM64.

Для ARM64 сделал отдельную проверку в CI на нативном Windows ARM64 runner. Проверяется не только тип PE-файла и способность Windows загрузить DLL: ARM64 Far реально запускается, находит FarFileClipboard через F11, после чего автоматический тест выполняет Copy и Paste через внутреннее меню плагина между двумя каталогами панели и проверяет появление файла в каталоге назначения.

То есть на данный момент автоматически проверяются:

- сборка x86 / x64 / ARM64;
- правильный PE machine type для каждой DLL;
- загрузка ARM64 DLL и наличие обязательных экспортов Far API;
- обнаружение плагина нативным ARM64 Far;
- реальная операция Copy/Paste внутри ARM64 Far.

Ручная проверка всё равно остаётся полезной для взаимодействия с Проводником, диалогов конфликтов, настроек и остальных UI-сценариев.
