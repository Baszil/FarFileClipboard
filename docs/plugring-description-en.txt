FarFileClipboard is a Far Manager 3 x64 plugin that connects a normal Far file panel to the Windows file clipboard. Supports Copy, Cut, Paste into the current panel directory, separate Paste into directory under cursor, and one-level safe Undo/Redo for operations performed by the plugin itself. Insert selection takes priority; otherwise the item under the cursor is used. Configurable hotkeys. Also supports pasting virtual Shell objects such as files copied from Explorer ZIP folders. English and Russian localization. Author: Qwaduda. Conflict handling is configurable: a FarFileClipboard dialog with explicit rename, Windows system behavior, or automatic rename with a configurable template.
