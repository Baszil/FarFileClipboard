FarFileClipboard — плагин для Far Manager 3 x64, связывающий обычную файловую панель Far с системным файловым буфером Windows. Поддерживает копирование, вырезание, вставку в текущий каталог панели, отдельную вставку в каталог под курсором и одноуровневую безопасную отмену/повтор операций, выполненных самим плагином. Выделение Insert имеет приоритет; если выделения нет, используется объект под курсором. Горячие клавиши настраиваются. Обработка конфликтов тоже настраивается: собственный диалог FarFileClipboard с явным переименованием, системное поведение Windows или автоматическое переименование по настраиваемому шаблону. Поддерживает также вставку виртуальных Shell-объектов, например файлов из ZIP Проводника. Русский и английский языки. Автор: Qwaduda.
